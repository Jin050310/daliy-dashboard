# T05 블라인드 비교와 도구 선택 기준

두 AI의 모델·서비스 이름은 이 문서 어디에도 적지 않는다. 작업 순서대로 **AI A**(먼저 작업, 중단 후 인수인계)와 **AI B**(인수인계 문서를 받아 완성)로만 부른다.

## 1. 블라인드 비교표

| 항목 | AI A | AI B |
|---|---|---|
| 실제 작업 시간 | 약 6분 (15:23–15:25 구현, 15:48–15:52 인수인계 문서) | 약 6분 (16:34–16:40) |
| 실제 요청·호출 수 (사람이 보낸 메시지) | 2회 | 1회 |
| 오류 수 (고정 검사 10개 중 FAIL이 1개 이상 나온 실행 회차 수) | 0 | 0 |
| 검사 통과 수 (작업 종료 시점) | 10/10 | 10/10 |
| 시작 고정 소스 버전 | `60f73e4` | `95b295b` |
| 종료 고정 소스 버전 | `22b8191` | `ea88e09` |
| 공통 상한 (작업 전 고정) | 60분 · 30회 | 60분 · 30회 |

- 날짜는 모두 2026-11-18, 시각은 Asia/Seoul.
- 재작업량(추가·삭제 줄 수)은 위 시작·종료 버전 쌍으로 채점기가 계산하므로 적지 않았다. 생성 파일(`site/`, `data/`)과 lockfile은 변경 대상이 아니다.
- AI A의 `22b8191` 이후 커밋 `95b295b`는 인수인계 문서와 기록 파일만 추가했고 코드는 바뀌지 않았다.
- 오류 수: AI A는 자기 세션 안에서 검사를 실행해 10/10을 보고했고, 종료 후 사람이 다시 실행해도 10/10이었다. AI B는 사람이 1회 실행해 10/10이었다. 실행 결과 원문은 `T05_records/`에 있다.

### 작업 조건 차이
| | AI A | AI B |
|---|---|---|
| 작업 방식 | 로컬 저장소에 연결된 에이전트가 파일을 직접 수정하고 검사를 실행 | 웹 채팅에 저장소 파일 5개를 첨부. AI가 수정 코드를 제시하고 사람이 그대로 적용·실행 |
| 받은 정보 | 최초 요청, `T05_준비.md`, 검사 파일 | 같은 최초 요청 + `HANDOFF.md`와 저장소 파일. 이전 대화는 받지 않음 |
| 맡은 범위 | 계산 함수 + 화면 연결(계획보다 앞서 진행), 인수인계 문서 | 화면 결과의 날짜 표시 문제 수정 |

두 AI가 맡은 일의 크기가 달라서, 시간·요청 수만으로 우열을 가리기는 어렵다.

## 2. 짧은 확인 방법

1. **어디로 가나요:** https://jin050310.github.io/daliy-dashboard/ 의 **기간 변동 조회** 카드
2. **무엇을 하나요 (3단계):** 시작일에 `2026-10-05` 입력 → 종료일에 `2026-10-14` 입력 → **기간 조회** 클릭
3. **무엇이 보이면 통과인가요:** `적용 기간 2026.10.06 ~ 2026.10.14 · 거래일 6일`과 `변동률 -13.87%`가 보인다. (10-05는 개천절 대체공휴일이라 다음 거래일 10-06부터 계산된다.)
4. **안 될 때 무엇이 보이나요:** 날짜가 `2026.-1.0-`처럼 깨져 보이거나, 결과 칸이 나타나지 않거나, 거래일 수·변동률이 위와 다르다.

코드 기준 확인: 저장소의 `nps_tracker` 폴더에서 `node --test tests/period.test.mjs` → `pass 10`, `fail 0`.

## 3. 다음 작업의 도구 선택 기준

여러 파일을 고치고 검사까지 돌려야 하는 구현은 저장소에 직접 접근하는 에이전트형 AI를 먼저 쓰고, 인수인계 문서로 원인이 정리된 작은 수정은 웹 채팅형 AI로 처리한다.

## 4. 역할 구분

### ① AI에게 맡긴 일
기간 변동 계산 함수와 화면 연결 구현, 인수인계 문서 작성과 새 폴더 재현 확인(AI A), 화면 날짜 표시 수정 코드(AI B), 검사 10개 초안·기대값 계산·기록 정리(보조 AI)

### ② 학생이 직접 판단한 일
두 날짜 비교안은 너무 쉬워서 기간 조회 기능으로 정했고, 상한을 60분·30회로 정했으며, 브라우저에서 직접 조회해 날짜 표시와 공휴일 처리를 확인하다가 최신 날짜가 안 보이는 문제(데이터 재생성 필요)를 찾았다.

### ③ AI 제안을 따르지 않은 일
AI B는 새 폴더와 로컬 에이전트로 작업하라는 권고를 받았지만, 로그인 문제로 시간이 늘어나 웹 채팅에 저장소 파일을 첨부하는 방식으로 바꿨다. 남은 작업이 날짜 표시 수정 하나로 작아서 충분하다고 판단했다.
